# Inkopia: The Luxury Pen Concierge Platform

Inkopia is a premium digital experience designed for high-end fountain pen collectors. The platform provides a seamless way to commission expert maintenance "Rituals" and manage a private collection of luxury writing instruments.

## Key Features
- **3D Interactive Landing Page:** A state-of-the-art visual experience featuring 3D pen animations and smooth scroll-driven storytelling.
- **Private Vault:** A secure dashboard for collectors to track their pens and service history.
- **Master Rituals:** A structured service protocol for cleansing, replenishment, and mastery of fine nibs.
- **Admin Command Center:** A centralized hub for managing commissions, site settings, and ink curation.

## Tech Stack
- **Frontend:** React, Vite, Framer Motion, Tailwind CSS.
- **Backend:** Node.js, Express, MongoDB.
- **Authentication:** Firebase (Google & Magic Link).
